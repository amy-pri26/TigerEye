# OTX Setup \& API Key Configuration



This document explains how to configure access to AlienVault Open Threat Exchange (OTX) for the TigerEye Alert Engine.



OTX is used as an OSINT enrichment source to provide threat intelligence on IP addresses, domains, URLs, and file hashes.




### 1. Create an OTX Account

1. Navigate to: [https://otx.alienvault.com](https://otx.alienvault.com)

2. Click Sign In

3. Create an account if you do not already have one.

4. Verify your email address if prompted.




**Each developer must create their own account.**




### 2. Retrieve Your API Key



Once logged in:



1. Click your profile icon (top-right corner).

2. Select Settings.

3. Scroll to the API Key section.

4. Click Show.

5. Copy your API key.





###### ⚠️ Important

Your API key is tied to your personal account.

- **Do NOT share it publicly.**
- **Do NOT commit it to GitHub.**
